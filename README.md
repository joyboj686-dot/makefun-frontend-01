# make.fun frontend

[![make.fun bounty](https://make.fun/badge/makefun-frontend-01.svg)](https://make.fun/bounty/makefun-frontend-01)
[![make.fun rank](https://make.fun/badge/makefun-frontend-01/joyboj686-dot/makefun-frontend-01/rank.svg)](https://make.fun/bounty/makefun-frontend-01/leaderboard)
[![make.fun reward](https://make.fun/badge/makefun-frontend-01/joyboj686-dot/makefun-frontend-01/reward.svg)](https://make.fun/bounty/makefun-frontend-01)

A fast, dependency-free static frontend for make.fun that reads the public API: a live bounty board with search, sort and category filters, bounty pages with per-place rewards, leaderboards and profile records.

## Run

```bash
node serve.ts
```

Then open <http://localhost:8080>.
